# Technical verbs

A technical verb shows a process in IT, data, or AI that a core verb cannot show.
Use a technical verb only when no core verb is sufficient (rule W10).
Write "start the job", not "launch the job".

Rules for technical verbs:

- Use a technical verb only as a verb. Use the noun for a noun (rule W11). Write "the deployment failed", not "the deploy failed".
- You can use the past participle as an adjective. Example: "the encrypted bucket".
- Do not use the "-ing" form (rule V3).
- Use a description verb only in descriptive text. Do not use it in a procedure.
- If your project needs a different technical verb, add it to the `ste-terms.md` file of your project. The template is `assets/ste-terms-template.md`.

Format: `VERB (v) [present, past, past participle]`
