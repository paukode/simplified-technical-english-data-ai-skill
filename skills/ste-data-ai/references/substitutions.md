# Substitutions

This file gives replacements for words and phrases that are not permitted.
The replacement must keep the meaning of the sentence.
If a word-for-word replacement is not clear, write a new sentence (rule G1).

The check script reads the tables in this file.
In the first column, there is a comma between the forms of the same word or phrase.
Text in parentheses in the second column is an instruction, not a replacement.

## Part 6: Words about models and agents

Do not give human qualities to a model or an agent (rule M1).
The check script uses this table only when the subject of the sentence is a model, an agent, or an assistant.
For persons, some of these words are permitted.

| Do not write about a model or an agent | Write | Rule |
|---|---|---|
| think, thinks, thought | calculate, generate, return | M1 |
| know, knows, knew | have data about, contain | M1 |
| understand, understands, understood | process, parse, classify | M1 |
| believe, believes, believed | (give the output and the score) | M1 |
| want, wants, wanted | (give the goal or the instruction) | M1 |
| decide, decides, decided | select | M1 |
| remember, remembers, remembered | store, keep in memory | M1 |
| forget, forgets, forgot, forgotten | delete, not keep | M1 |
| learn, learns, learned | train (the model) | M1 |
| hallucinate, hallucinates, hallucinated | generate incorrect information | M1 |
| lie, lies, lied | return incorrect output | M1 |
| feel, feels, felt | (remove it) | M1 |
| see, sees, saw | receive, read | M1 |
| realize, realizes, realized, notice, notices, noticed | detect, find | M1 |
| cheat, cheats, cheated | (describe the output) | M1 |
| confused | (describe the incorrect output) | M1 |
