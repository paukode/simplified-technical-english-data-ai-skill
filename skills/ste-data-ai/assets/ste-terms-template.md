# Technical names: <your project>

Copy this file to the root folder of your project. Give it the name `ste-terms.md`.
The check script reads `ste-terms.md` from the current folder.
You can also give a file to the script with the `--terms` option.

Add the names of your systems, tables, teams, products, and documents.
Add the technical verbs that your project uses.
Do not add a word that `substitutions.md` does not permit.

## Names

Write the names as bullet lines. Separate the names with a comma and a space.
Put the short name in parentheses after the full name.

<!-- Examples:
- Customer Data Platform (CDP), order service, payments team
- fact_orders, dim_customer, Platform Runbook
-->

## Verbs

Write one verb on each line, in this format:
`VERB (v) [present, past, past participle]`

<!-- Example:
REPLATFORM (v) [replatforms, replatformed, replatformed]
-->
